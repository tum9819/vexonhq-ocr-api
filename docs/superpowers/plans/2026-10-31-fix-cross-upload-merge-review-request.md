1. ตาราง §3 ก่อน/หลัง ถูกต้องตามโค้ดจริงทุกแถวไหม แถวไหนผิด

3. 409 ไหลถึง client จริงไหม (ไม่ถูก `except Exception` แปลงเป็น 500 ระหว่างทาง) ทั้งเว็บและ LINE; frontend เดิมแสดงข้อความและไม่เปิด modal จริงไหม
4. การลบ storage ตอน 409 ลบเฉพาะไฟล์ของคำขอนี้ และไม่มีแถวใดอ้างถึงจริงไหม (รวม PDF หลายหน้าที่หน้าก่อนหน้าบันทึกไปแล้ว)
5. PDF หลายหน้าไฟล์เดียว / multi-bill PDF ที่เป็นบิลใหม่ทั้งหมด / retry ไฟล์เดิม — ยังทำงานเหมือนเดิมจริงไหม
6. test ใน §5 พอสำหรับพิสูจน์ (A)/(B) ไหม test เดิมตัวไหนจะต้องเปลี่ยน

## รูปแบบคำตอบ
ตารางเดียว: `# | (A)/(B)/นอกขอบเขต | ความรุนแรง | หลักฐาน ไฟล์:บรรทัด | ปัญหา | ข้อเสนอแก้`
ปิดท้าย verdict: `APPROVE` / `APPROVE WITH CHANGES` / `REJECT` — REJECT ได้เฉพาะเมื่อพบ (A) หรือ (B) จริง
